# Shareable aggregate leakage experiment outputs

These checked tables and 300-dpi figures were copied from private runs under `runs/leakage/`. The methods, exact execution status, interpretation and limitations are in `../LEAKAGE_ANALYSIS.md`.

The CSV files cover the full-dataset duplicate audit, controlled split class counts, six matched training/validation histories, six own-test and common-subset evaluations, 2,000-resample confirmed-group confidence intervals, paired common-subset differences, controlled-test degradation confusion matrices and fixed review-flag coverage. Figures show per-seed split comparisons, per-seed common-subset comparisons and mean controlled-test degradation trends.

No retinal photograph, image ID, image hash, per-image score, checkpoint or Kaggle credential is in this directory. Private group members, visually verified near-pair IDs, split manifests, full checkpoint weights, per-image predictions and feature caches remain under ignored directories. The duplicate-controlled experiment is **not patient-level validation**; 457 perceptual candidates have not been exhaustively reviewed.
