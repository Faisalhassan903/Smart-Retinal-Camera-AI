# Shareable aggregate publication outputs

These CSV tables and 300-dpi figures were copied from the private image-analysis run `runs/publication/20261126T160952168783Z`. See `../PUBLICATION_EXPERIMENTS.md` for methods and interpretation. The run used the original APTOS 2019 labelled photographs, preserved train/validation/test manifests, and the unchanged one-epoch checkpoint with SHA-256 `b968f81ebe724b45cf55081200e276ec7aa49606bc2faaa873e241e896d561c2`.

The directory contains no retinal photographs, credentials or per-image predictions. Exact and perceptual duplicate pair lists, image hashes, per-image scores and the visual review sheet remain in the ignored private run directory. Do not infer patient-level independence or clinical validation from these aggregate outputs. The original test estimate is affected by confirmed cross-partition exact duplicates; `exact_duplicate_sensitivity.csv` is a post hoc descriptive check, not a corrected independent estimate.
